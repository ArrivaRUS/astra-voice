## E1. Установка и онбординг

**US-1.1** · P0 · v0.1 · F1
As a П2/П3, I want установить утилиту одним deb из репозиториев Astra без сети в postinst, so that установка проходит штатным `apt` и не зависит от интернета.
- Given чистая ALSE 1.8, When `apt install ./astra-voice_X.Y.Z_amd64.deb`, Then зависимости разрешаются из репозиториев Astra, postinst не выходит в сеть и не запускает GUI, в меню появляется «Astra Voice».

**US-1.2** · P0 · v0.1 · F1, F14
As a П1, I want на первом экране выбрать язык и решить, выходить ли утилите в сеть, so that ни один запрос не ушёл без моего согласия.
- Given первый запуск, When показан экран 1, Then оба тумблера («обновления утилиты», «обновления моделей») **пусты**; пока не включены — сетевых запросов нет; включённое сохраняется в настройках; при `policy.conf: offline=true`/`profile=secure` тумблеры заблокированы («Задано администратором»).

**US-1.3** · P0 · v0.1 · F1, F7
As a П1, I want скачать рекомендованную модель одной кнопкой с прогрессом и проверкой, so that диктовка заработала без ручных действий.
- Given экран 2 и доступный HF, When «Скачать» у GigaAM v3 RNN-T, Then показан хост и объём, прогресс с процентами/скоростью/«Отмена», после загрузки sha256 совпал с манифестом и модель «Активна».
- В v0.1 допустимо: только модель по умолчанию (встроенный манифест из одной записи).

**US-1.4** · P1 · v0.2 · F7
As a П1 в закрытом контуре, I want установить модель из папки/файла, so that работать без интернета.
- Given нет сети, When выбираю папку с файлами модели, Then файлы проверены по sha256 из манифеста, модель установлена и активна; неизвестный набор → «Своя модель» (P2).

**US-1.5** · P0 · v0.1 · F1, F2
As a П1, I want задать комбинацию и режим (удерживать / нажать-нажать) на экране онбординга, so that хоткей был моим с первого запуска.
- Given экран 3, Then предзаполнено `Ctrl+Space`, режим «удерживать»; When нажимаю другую комбинацию, Then она захвачена, показана и сохранена; режим выбран переключателем; при захвате занятой комбинации — ошибка захвата по US-11.2.
- Ревизии 7–8: Given обнаружен Astra Cowork (F17.2), Then на экране 3 вторая строка «Команда помощнику» со своей клавишей (предзаполнена **одиночная Win** — решение заказчика 2026-09-15; под строкой подпись «Пока Astra Voice работает, клавиша Win не открывает меню приложений — она нужна для команды помощнику. Можно выбрать другую клавишу» и кнопка «Выбрать другую»; продолжение = согласие; при `BadAccess` — замена по US-1.5b), обе через пробник (US-1.5b); Given Cowork не найден, Then строки нет и вторая клавиша не регистрируется, меню по Win не меняется (US-2.10). Текст экрана 3a «Astra Voice заменяет Handy» — простым языком, без путей и имён служб.

**US-1.5b** · P0 · v0.1 (ревизия 6: живой пробник — Must v0.1; имя действия KDE — P1 v0.2; ревизия 7: вторая комбинация — вместе с US-2.10) · F1, F2, F17.4
As a П1, I want до сохранения узнать, что комбинация занята — другой программой или шорткатом KDE, — и сразу выбрать свободную, so that хоткей не сломал привычные действия и не оказался «в никуда».
- Given комбинацию держит другая программа (Handy на `Ctrl+Space`), When ввожу или подтверждаю её, Then пробник `XGrabKey` даёт `BadAccess` **до** записи настройки, показано «Комбинация занята другой программой (возможно Handy или переключатель ввода)» и список свободных комбинаций по живому скану (каждый кандидат проверен пробником, не по файлу); выбранная захватывается с первого раза; трей — `nokey` (US-11.2, спека §9.1). Given комбинация занята в `kglobalshortcutsrc`, Then предупреждение с именем действия KDE; выбор остаётся за мной (не запрет) — P1, v0.2.
- Ревизия 7 (две комбинации): Given заданы комбинации для «Текст» и «Команда помощнику», Then каждая проходит пробник отдельно до сохранения, совпадение запрещено («Уже используется для режима «Текст»»); Given одна из двух не захвачена при старте, Then вторая работает, трей `nokey` называет режим, уведомление «Выбрать другую» относится к нему. Given дефолт «Команда» (Win) занят другой программой, Then для строки «Команда» — «Клавиша занята другой программой» и свободные по живому скану (первыми `Win+Space`, `Ctrl+Shift+Space`), строка «Текст» сохраняется независимо; после освобождения таймер (US-2.11) захватывает дефолт сам, кнопки «Повторить» нет.
- Ревизия 8 (факты пробника 2026-09-15, KDE заказчика, Handy остановлен): `Ctrl+Alt+Space` занята и без Handy (владелец — не Handy и не мы; в чистой X свободна; кандидаты — демоны Fly в KDE-сеансе) — поэтому не дефолт «Команды»; `Alt+Space` = KRunner; свободны `Ctrl+Shift+Space`, `Win+Space`, `Ctrl+Alt+D`, `Ctrl+Alt+V`; одиночная `Super_L` захватывается. Список свободных в скане — по этим фактам, но всегда живой (пробник на каждой машине).

**US-1.6** · P0 · v0.1 · F1, F6
As a П1, I want проверить микрофон и увидеть распознанную тестовую фразу, so that убедиться, что всё работает, до реальной диктовки.
- Given экран 4, When говорю фразу, Then индикатор уровня двигается, через ≤ 1 с после отпускания текст на экране, вставки в другие окна нет.
- Ревизия 9 (решение заказчика 2026-09-16, PRD F1.4 экран 4, S1-A5): экран — из двух частей. Given модель ещё не установлена, When открываю экран 4 и говорю, Then индикатор уровня двигается, «Слышим вас» — проверка микрофона работает без модели, кнопка «Тестовая диктовка» неактивна с подписью «Будет доступно после установки модели», экран проходим; Given модель установлена, When нажимаю «Тестовая диктовка» и говорю, Then текст через ≤ 1 с на экране, в другие окна не вставлен.
- Ревизия 9: выключенный или слишком тихий микрофон на этом экране — US-11.7/11.8; границы открытого микрофона при проверке (индикация, потолок 180 с, остановка при невидимом окне) — US-11.10.

**US-1.7** · P1 · v0.2 (заказчик 2026-09-07) · F1, F10
As a П1, I want на последнем экране включить автозапуск и получить подсказку с хоткеем, so that завтра утилита уже работала.
- Given экран 5, When «Готово» с тумблером вкл, Then создан `.desktop` (US-8.2), окно свёрнуто в трей, уведомление «зажмите <хоткей>».

**US-1.8** · P1 · v0.2 · F11
As a П1, I want запустить онбординг заново из настроек, so that поправить хоткей/микрофон, не ища их по разделам.

## E2. Диктовка

**US-2.1** · P0 · v0.1 · F2
As a П1, I want зажать глобальный хоткей поверх любого окна и говорить, so that текст появился без переключений.
- Given утилита в трее, When зажимаю хоткей и говорю, Then запись идёт до отпускания, без root и группы `input`; комбинация работает при активном любом X11-окне.
- **Принято 2026-09-15 (M4 ✅)**: живой прогон Ц2 на `0.1.0~m4.4` — 50/50 диктовок, p50 233 / p95 291 мс (S2-A1); первая живая диктовка у заказчика — 14.09 («работает!»).

**US-2.2** · P0 · v0.1 · F2
As a П1, I want режим «нажал — говорю — нажал», so that диктовать длинные фразы, не держа клавишу.
- Given режим toggle, When нажимаю, говорю 10 с, нажимаю, Then запись между нажатиями, текст вставлен; отдельная комбинация не конфликтует с push-to-talk.

**US-2.3** · P0 · v0.1 · F2
As a П1, I want отменить запись клавишей Esc, крестиком в пилюле или из трея, so that не вставить лишнее.
- Given идёт запись, When Esc / «×» / «Отмена», Then аудио отброшено, вставки нет, трей «готов».
- **Проверено 2026-09-15 (T-56 живьём)**: после ошибки/смены микрофона во время записи хоткей не залипает, `Esc` и повторное нажатие работают, следующая диктовка начинается штатно.

**US-2.4** · P0 · v0.1 · F2
As a П1, I want чтобы случайные нажатия игнорировались, а длинная речь не обрезалась, so that не получать мусор и не терять слова.
- Given нажатие < 0,3 с, Then ничего не вставлено и нет ошибки. Given запись 120 с, Then автостоп + распознавание + подсказка. Given фраза 40 с, Then сегментация по паузам, порядок слов сохранён.

**US-2.5** · P0 · v0.1 · F4
As a П2, I want чтобы распознавание шло в отдельном процессе, so that крах движка не убивал утилиту.
- Given воркер убит `kill -9`, When зажимаю хоткей, Then воркер перезапущен (≤ 3 раз/10 мин), диктовка работает, GUI не падал.

**US-2.6** · P1 · v0.2 · F4
As a П2, I want выбрать, держать ли модель в памяти или выгружать через N минут, so that балансировать отклик и ОЗУ.
- По умолчанию модель держится в памяти постоянно (заказчик 2026-09-07). Given «выгружать через 5 мин», When прошло 5 мин простоя, Then RSS воркера упал до базового; следующая диктовка показывает «Загружаю модель…» и работает.

**US-2.7** · P1 · v0.2 · F2
As a П1, I want начать новую запись, пока предыдущая распознаётся, so that не ждать между фразами.
- Given идёт распознавание, When начинаю запись, Then она принята, обе вставки приходят по порядку.

**US-2.8** · P0 · v0.1 · F4, §10
As a П2, I want видеть локальную статистику задержки «отпустил → текст», so that проверить паритет с Handy цифрами, а не ощущениями.
- Given ≥ 50 диктовок, When открываю «О программе → Статистика», Then вижу медиану и p95 `t_ms` по модели; данные никуда не отправлены.
- **Принято 2026-09-15**: статистика `--stats` дала цифры приёмки Ц2 (50 событий: `t_ms`, `paste_ms`, `audio_ms`, `result`, `cold`; текста фраз в статистике нет по конструкции) — `spikes/m4_live/events-2026-09-15-m4.4.json`.

**US-2.9** · P2 · после v1 · F2
As a П2, I want «надёжный режим» захвата через evdev, so that хоткей работал, даже если XGrabKey конфликтует.
