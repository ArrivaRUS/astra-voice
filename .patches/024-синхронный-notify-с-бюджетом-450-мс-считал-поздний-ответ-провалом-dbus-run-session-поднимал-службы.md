# 024 · Синхронный `Notify` с бюджетом 450 мс считал поздний ответ провалом; `dbus-run-session` сам поднимал службы

**Дата:** 2026-09-28. **Где:** m6.23 у заказчика — два WARNING «Не удалось показать уведомление» в журнале при том, что
сообщения на экране были; фикс — PR #10 `wip/r1-notify` (`src/astra_voice/ui/notify.py`).

## Что случилось
1. `notify.py` вызывал `Notify` через `bus.call(..., QDBus.Block, ≤450 мс)` в GUI-потоке и любой не-`ReplyMessage` считал
   недоставкой. В прошлой загрузке Plasma тормозила (у стороннего Electron-приложения в `journalctl --user -b -1`
   `notify_notification_show` висел по 25 с): сообщение показано, ответ опоздал → ложный WARNING, `_last_id=0` (нет
   замены через `replaces_id`, кнопки уведомления «неизвестного id» не работают), сообщение в `_pending` → дубль при
   перерегистрации значка, заморозка GUI до 450 мс. Дефект с 14.09, проявился только при медленном сервере.
2. debugger и developer воспроизводили на своей шине: стандартный `dbus-run-session` читает каталоги служб и **сам
   активировал `/usr/bin/fly-notifications`**, когда имя было свободно (упал без X; plasmashell заказчика цел). Тот же риск
   был в существующих `tests/unit/test_tray_dbus_lifetime.py`.
3. Фейковый сервер Codex хранил аргумент слота `QDBusMessage` → SIGSEGV (класс урока 022).

## Правило на будущее
1. **Вызовы D-Bus к чужим службам — асинхронно** (`asyncCall` + `QDBusPendingCallWatcher`, watcher жив до ответа,
   ответ сразу в Python-данные). Таймаут ≠ недоставка: разбирать `errorName()` (`NoReply`/`Timeout` — «могло быть
   доставлено», без повтора; `ServiceUnknown`/`NameHasNoOwner`/`Disconnected`/`Spawn.*` — не доставлено). Повтор без
   срока давности и без защиты от дублей — запрещён.
2. **Тестовая шина — только через `tests/helpers/private_bus.py`**: свой конфиг без `servicedir`/`include`, чистое
   окружение, группа процессов, «Activating service» в stderr = провал теста. Голый `dbus-run-session` в тестах не использовать.
3. Живой фидбек «сообщения видел» против журнала «не удалось» — сразу гипотеза «поздний ответ», не «не доставлено».
