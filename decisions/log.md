## 2026-09-09 — M1: рендер Qt Quick по умолчанию — программный (RSS 168 → 103 МБ)
- Контекст: DoD M1/PRD A1 — GUI в покое ≤ 120 МБ; факт на машине заказчика 167 740 кБ. Optimizer (`spikes/m1_live/rss.md`):
  35 % RSS — Mesa + `libLLVM-16` (58 МБ), грузятся при любом GL-контексте (Mesa 24.x, `iris` внутри `libgallium` с LLVM);
  `QT_QUICK_BACKEND=software` **вместе с** `QT_XCB_GL_INTEGRATION=none` → 102 580 кБ (−38,8 %), кропы текста/знака/иконок/
  скруглений/чипа/тумблеров совпадают, CPU при наведении +1,3 п.п. одного ядра, анимация переключения дешевле; `MALLOC_ARENA_MAX`,
  `malloc_trim`, стиль/тема, EGL — шум; лишних импортов и QML-модулей нет.
- Решение: **по умолчанию программный рендер** (обе переменные в `bootstrap.py` для `app`), переключатель `ASTRA_VOICE_RENDER=gl`;
  пользовательские `QT_*` не перебиваются; сообщения Qt о GL-фолбэке — в наш журнал, не в stderr. Порог A1 остаётся 120 МБ.
- Почему: порог выполнен с запасом без потери качества; плюс независимость от GL-стека (ВМ ALSE без ускорения, ЗПС-контур);
  `QGuiApplication` вместо `QApplication` (ещё −4,7 МБ) — не сейчас, ломает QWidget-заглушку.
- Гейт: — (DoD M1). Последствия: сборка 0.1.0~m1.2; при жалобах на рендер — `ASTRA_VOICE_RENDER=gl` в `INSTALL-ADMIN.md`.

## 2026-09-09 — «Мерцание» сайдбара = hover-анимация; правило motion: наведение без анимации
- Контекст: Debugger (`spikes/m1_live/flicker.md`) в изоляции не нашёл причины в коде (перерисовка только пункта, xprop без
  изменений, 9 кадров на вход/выход = анимация 120 мс), гипотеза GL/PSR требовала живого шага. Живой шаг с заказчиком
  (4 варианта: обычный, пробное QML, `QSG_RENDER_LOOP=basic`, `QT_QUICK_BACKEND=software`): «есть во всех четырёх» —
  заказчик: «это просто такая убогая анимация выбора пункта меню… воспринялась как баг. Надо её поменять».
- Решение: **hover — мгновенный, без переходов** во всех контролах (сайдбар, кнопки, сегмент, селект, строки); анимация
  остаётся только у смены выбранного пункта (ease-out ≤ 120 мс, без пролёта через яркие цвета) и у ручки тумблера.
  Рендер-бэкенд не меняем (software/basic не нужны). Спека и макет — UX-analyst; QML — M1-C; токены `motion.hover-*`,
  если есть, — устаревшие (design-engineer).
- Почему: живой факт заказчика + инструментальный (кадры только в момент входа/выхода) — серия 120-мс переходов при
  движении мыши читается как мерцание; минималистичный UI без hover-анимаций ближе к принятому направлению «Панель».
- Гейт: — (решение заказчика на живом показе). Последствия: дефект 2 живого показа закрыт причиной; повторная проверка —
  после пересборки `.deb` и переустановки у заказчика.
