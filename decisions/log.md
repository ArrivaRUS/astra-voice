## 2026-09-09 — Fly-сессия: адаптеры (из §13 плана #1) — вход в синтез
- fly-wm поддерживает нужный EWMH и **сам реализует StatusNotifierWatcher** (SNI есть), но перекраску иконок по имени
  делает только Plasma → во Fly трей-иконки с явными цветами (второй набор файлов); тема — из `~/.fly/paletterc`
  (на машине kdeglobals и paletterc расходятся: KDE Dark / Fly Light) → детект по `XDG_CURRENT_DESKTOP`;
  клип-менеджер fly-wm пишет буфер в `~/.fly/clipboard` → при «не оставлять текст» использовать тип из его чёрного
  списка; polkit-агент и D-Bus-уведомления (fly-notifications, actions) общие; автозапуск ведёт fly-wm сам (XDG,
  без systemd); `Ctrl+Space` во Fly свободен; `/etc/X11/Xsession.d/06-fly-misc-env` навязывает
  `QT_QUICK_CONTROLS_STYLE=org.kde.desktop` → лаунчер принудительно ставит наш стиль; новый риск R17 —
  `astra-interpreters-lock` (блокировка интерпретаторов) не даст запустить Python-лаунчер, только исключение админа.
- Не проверено без Fly-сессии (список §13.2) → спайки S1/S4/S5 и E2E — в обеих сессиях; чистая ВМ ALSE 1.8 нужна.

## 2026-09-09 — Требование заказчика: .deb, который любой человек поставит на современную ALSE, в идеале без прав администратора
- Контекст: заказчик (чат 2026-09-09). Противоречие: `.deb` ставится только через dpkg/apt = root/polkit. «Без админских
  прав» = второй путь — пользовательская установка в `~/.local` (XDG-меню и автозапуск работают без root; ЗПС — нет).
  Упирается в зависимости: стоковая ALSE 1.8 имеет `python3-pyqt5` (QtWidgets — на нём утилиты Астры), но
  `python3-pyqt5.qtquick` и QML-модули без root не поставить; вендорить PyQt5 из pip = ~100 МБ и десятки `.so`.
- Решение: **пока не принято** — архитектор #1 готовит разбор «установка без прав администратора» (факты по стоковым
  пакетам ALSE, варианты: QtQuick (как спека) + только .deb · QtWidgets+QSS с нулём apt-зависимостей сверх стока +
  .deb и пользовательский бандл · гибрид). Выбор — заказчику на ⛔ G4 с рекомендацией Юрки.
- Гейт: G4 (открыт). Последствия: может измениться GUI-стек (спека остаётся источником визуальной истины, меняется
  реализация) и упаковка (два артефакта: .deb + user-bundle).

## 2026-09-07 — Рамки продукта до PRD: аудитория/ЗПС, лицензия, индикация записи
- Контекст: ресёрч платформы показал, что при включённой ЗПС (digsig) самообновление «одной кнопкой»

  1. **Оба режима обновления в v1**: без ЗПС — GitHub Releases → .deb → polkit → apt из GUI;
