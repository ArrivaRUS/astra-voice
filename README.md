# Astra Voice

Голосовой ввод для Astra Linux SE: зажали горячую клавишу, сказали фразу — текст появился
в активном окне. Распознавание полностью офлайн, на процессоре, движок GigaAM v3 (русский язык,
пунктуация) плюс модели Whisper на выбор.

**Статус:** веха M1 — скелет приложения, упаковка в `.deb`, гейты сборки и CI.
Продукт ещё не выпущен: публичных релизов и подписанных пакетов нет.
Рабочее имя — временное.

## Что будет
- Выбор модели распознавания: GigaAM v3 RNN-T (по умолчанию) и варианты Whisper, с честными
  цифрами — размер на диске, память в работе, полоски «качество» и «скорость».
- Проверка обновлений модели при запуске и обновлений самой утилиты; установка из интерфейса.
- Автозапуск вместе с системой.
- Современный минималистичный интерфейс на русском языке.

## Установка

Пакет ставится **администратором** — это системная операция:

```sh
sudo apt install ./astra-voice_<версия>_amd64.deb
astra-voice --version
```

Порядок проверки подписи, работа в закрытом контуре и удаление — в
[`packaging/INSTALL-ADMIN.md`](packaging/INSTALL-ADMIN.md).

Установка без прав администратора (пользовательская сборка в `$HOME`) в v1.0 не
поддерживается и запланирована на v1.1.

### Ключ подписи релизов

Релизы подписываются офлайн-мастером заказчика; публичная часть лежит в
[`data/keys/release.gpg`](data/keys/release.gpg) и попадает в пакет.

> **Сейчас в репозитории лежит ТЕСТОВЫЙ ключ** с отпечатком
> `CB95 1AD7 9440 7972 A0B1  A5BB AFA8 7398 C495 3A71` — он существует только
> для проверки цепочки `gpgv` → пин отпечатка. Мастер-ключ заказчика будет
> сгенерирован до 25.09.2026, после чего отпечаток появится здесь.
> Пакетам, подписанным тестовым ключом, доверять нельзя.

Схема ключей, ротация, действия при компрометации и канал сообщений об
уязвимостях — [`docs/SECURITY.md`](docs/SECURITY.md).

## Что уходит в сеть

Ни звук, ни распознанный текст — никуда. Четыре сетевых обращения (каталог моделей,
скачивание весов, проверка обновлений, скачивание пакета) описаны в
[`docs/PRIVACY.md`](docs/PRIVACY.md); политика администратора отключает их полностью.

## Сборка из исходников

```sh
make wheels          # один раз: скачать колёса по packaging/wheels.lock (нужна сеть)
make deb             # сборка; в debian:12, если доступен podman/docker, иначе на хосте
make lint && make test
```

Готовый пакет — `dist/astra-voice_<версия>_amd64.deb`, состав — `dist/sbom.cdx.json`.
Гейты сборки (`tools/elf-audit`, `tools/deps-audit`) считают собственные ELF в пакете,
проверяют максимальную требуемую glibc и сверяют зависимости колёс с версиями в apt.

## Откуда растёт
Предшественник — сборка [Handy](https://github.com/cjpais/Handy) с GigaAM v3
(`ArrivaRUS/handy-gigaam`): фраза 6 секунд распознаётся за ~130 мс на Intel Core Ultra 7 без GPU.
