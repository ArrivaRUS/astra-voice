# Astra Voice — голосовой ввод для Astra Linux (astra-voice)

> Карточка проекта. Заведена на интейке (`/idea`). **Обновлено:** 2026-09-07
> Рабочее имя «Astra Voice» — временное; варианты нейминга предлагает brand-designer, выбор — за заказчиком (G2a).

## Идея (одна строка)
Утилита голосового ввода для Astra Linux SE (ALSE), написанная с нуля: зажал хоткей → говоришь → распознанный текст вставляется в активное окно; движок — GigaAM v3 RNN-T (русский, офлайн, CPU) плюс варианты Whisper; современный минималистичный интерфейс; обновления модели и самой утилиты из GUI; автозапуск.

## Контекст
- Проблема: сейчас голосовой ввод на машинах заказчика — переделанный Handy (Tauri+React+Rust, форки `Handy` и `transcribe-rs`, репо `ArrivaRUS/handy-gigaam`). Работает отлично (фраза 6 с → ~130 мс, пунктуация, «ё»), но это чужой форк с тяжёлым стеком сборки, английским UI, чужой айдентикой и хрупкой упаковкой (tauri CLI не собирает, deb перепаковывается руками). Нужна своя утилита под ALSE.
- Для кого: русскоязычные пользователи Astra Linux SE 1.8 (KDE Plasma 5 / Fly, X11) — сотрудники заказчика и корпоративные пользователи ALSE.
- Провенанс: запрос заказчика в чате 2026-09-07 после успеха Handy+GigaAM (2026-09-01…04); соседний проект — `~/Документы/handy-gigaam`.

## Исходные требования заказчика (дословно по смыслу, 2026-09-07)
1. Выбор модели, которую используем сейчас (GigaAM v3 RNN-T ONNX int8); при запуске утилиты проверять, нет ли обновлений этой или близкой к ней модели.
2. Выбор различных вариантов Whisper.
3. Показывать размеры моделей и сколько они занимают памяти в работе; две полоски (как в Handy) — качество и скорость.
4. Самопроверка на обновления утилиты, индикация пользователю (как у Handy — строчкой внизу интерфейса) и установка обновления через GUI самой утилиты.
5. Настройка автозапуска вместе с загрузкой ОС.
Плюс: современный стильный минималистичный интерфейс; графическая айдентика и иконка от дизайнера; публичный репозиторий на GitHub.

## Риск-теги (маршрут по риску, интейк 2026-09-07)
- `арх-граница` — новый проект с нуля: полный цикл, двойной архитектор обязателен.
- `права` — самообновление утилиты требует root/polkit; доверие к скачанным пакетам и моделям
  (подпись/sha256 — supply chain) → T1 модель угроз на проектировании, T2 при правках обновлятора.
- `ОС/сеть` — автозапуск, глобальные хоткеи, звук (гонка WirePlumber), вставка текста в чужие окна,
  ЗПС → P21½ боевой прогон на реальной машине ALSE перед релизом.
- `необратимо` — публичный репо и публичные релизы → G5 на каждый выпуск, откат известен.
- `данные` (низкий) — голос обрабатывается локально, записи по умолчанию не хранятся; ПДн третьих лиц
  в надиктованном тексте — ответственность пользователя (см. `research/legal.md`).

## Цель
Заменить Handy на рабочих машинах ALSE: та же скорость и качество распознавания (GigaAM v3), нативный русский UI, катaлог моделей с честными цифрами (размер/ОЗУ/качество/скорость), обновления модели и утилиты из интерфейса, автозапуск, установка одним deb-пакетом.

## Целевая среда (проверено на машине заказчика 2026-09-07)
- Astra Linux SE 1.8.5, X11, KDE Plasma 5.27 (Fly-DM), glibc 2.36, Python 3.11.2.
- В apt: PyQt5 5.15.9 (есть), GTK4 4.8.3 (есть), Qt6 6.4.2 (только библиотеки, без python-биндингов), WebKitGTK 2.50; PyQt6/PySide6 в apt нет (только pip).
- Железо: Intel Core Ultra 7 255U (14 потоков), 30 ГБ ОЗУ, CPU-only.
- ЗПС/digsig на этой машине выключен (DIGSIG_ELF_MODE=0), но у корпоративных пользователей может быть включён — учитывать при упаковке/самообновлении.
- Модели Handy лежат в `~/.local/share/com.pais.handy/models/` (gigaam-v3-rnnt-int8 222 МБ, whisper-medium-q4_1 470 МБ, ggml-small 466 МБ).
