# Целевой макет «Команда помощнику» — 2026-10-08

Статус: дизайн для передачи инженеру и независимому design_reviewer; реализация ещё не сверена. Исходная ревизия `bcde2e7fdb345832e7fc8b209a4d84ecf65a862a`, ветка `codex/command-settings-layout`. Дизайн сформирован по исходному снимку пользователя и компонентам HEAD, без чтения candidate diff.

Наглядный target: [command-settings-layout.svg](mockups/command-settings-layout.svg). Три панели показывают всю карточку настроек при двух ширинах и редактор мастера при активном захвате. Внутренний вид CaptureField на SVG схематичен: нормативны его ширина и положение, сам существующий компонент не перерабатывается. Размеры — логические px при масштабе 100 %. Подписи размеров снаружи панели не входят в интерфейс.

## Состав и геометрия

Источник значений: design/spec.md §3.1–3.2, §4.1, §7 и qml/Theme.qml. Горизонтальные поля — Theme.cardRowPaddingX=14; нижнее поле — Theme.cardRowPaddingY=7; gap=8 — сохранённый шаг существующего CommandHotkeySettings (совпадает с Theme.fieldGap / Theme.spaceGroupGap); размеры кнопок — Theme.buttonHeightSm / Theme.buttonSmPaddingX.

Сохраняются Theme, SettingGroup, SettingRow, AvButton, KeyChip, CaptureField и AvToggle. Соседние карточки, их ширины, высоты строк и расстояния между группами не меняются. Вся группа настроек сохраняет CAPS-заголовок, 5 px до карточки, границу 1 px, радиус 10 и фон bgSurface. Новая вложенная рамка внутри карточки не нужна.

| Контекст | Окно | Ширина карточки / редактора | Ширина внутреннего блока |
|---|---:|---:|---:|
| Настройки | 900 | 672 | 642 |
| Настройки | 1035 | 796 | 766 |
| Мастер, шаг 3 | 900 и 1035 | 580 | 552 |

Настройки: `min(796, windowWidth − 184 − 2×22)`, поэтому при 1035 ширина уже ограничена 796. Граница карточки оставляет ширину дочернего редактора `C = W − 2`. Пояснение, кнопки и поле захвата имеют x=14 внутри редактора и width=C−28; относительно внешнего края карточки x=15. Мастер сохраняет существующий отдельный редактор шириной 580, без новой рамки и без нижних переключателей; x=14, width=552. Он стоит через 16 px после блока текстовой клавиши / её активного поля захвата, как в существующем Step3Hotkey.

Внутри редактора сверху вниз:

1. Полная SettingRow без верхнего разделителя: «Команда помощнику», под ней текущий `commandStatus`; справа существующие «?», KeyChip и «Выбрать другую». Внутренние поля 7 по вертикали / 14 по горизонтали; высота минимум 55, растёт по фактическому переносу длинного статуса. Чип и кнопка по вертикальному центру. Кнопка sm=28 px, чип=26,5 px. Правый край кнопки — на линии правого внутреннего поля.
2. Через 8 px — пояснение в общей внутренней колонке. Размер 12, цвет fgMuted, фиксированная высота строки 18 (Theme.fontSettingSubLineHeight=1.5). WordWrap; никаких отрицательных полей или обрезки. Высота по содержимому.
3. Через 8 px — ряд «Левая Win», «Правая Win», «Проверить снова», gap=8, высота 28, первые две secondary, третья ghost. Ряд начинается на той же линии x=14, что пояснение и верхняя подпись. Ширина кнопок по существующему AvButton: текст + 2×9; не растягивать на всю карточку. На всех трёх назначенных ширинах ряд помещается целиком.
4. Только для command captureState != idle: через 8 px — существующий CaptureField в той же внутренней колонке, `showIdleRow=false`; все состояния и действия сохраняются, высота определяется его implicitHeight. Не показывать второй idle-редактор.
5. После последнего видимого элемента — 7 px (Theme.cardRowPaddingY) нижнего поля, затем штатный разделитель первой toggle-строки (только настройки).
6. Две SettingRow с существующими подписью, пояснением, значком «?» и правым переключателем. Каждая по 56 px (55 + разделитель 1); горизонтальные поля 14, вертикальные 7. «Голосовые команды» / «Передавать команды в Astra Cowork»; «Показывать команду перед отправкой» / «Три секунды для отмены. Esc — не отправлять». Значения и enabled — существующего моста. На весь ряд не добавлять обработчик переключения в рамках этой правки.

Итоговая высота настроек в покое: `2 + Htop + 8 + Htext + 8 + 28 + 7 + 56 + 56`. При Htop=55 и двух строках пояснения Htext=36 — 256 px. При трёх строках Htext=54 — 274 px. Переносы в SVG иллюстративные; критерием является отсутствие обрезки и формула реальной высоты текста, а не совпадение слов на каждом переносе. Нет фиксированной общей высоты редактора. Высота мастера — та же формула верхнего блока без 2 px рамки и 112 px переключателей; активный CaptureField добавляет 8 + его высоту. При нехватке высоты используется существующая вертикальная прокрутка страницы.

## Текст пояснения

«Win запускает запись команды вместо меню приложений. Для команд рекомендуем „Удерживать“: пока Win зажата, сочетания с ней не работают.»

В интерфейсе использовать обычные русские кавычки «Удерживать». Пояснение сохраняет ограничения Win/PTT и не обещает автоматического возврата меню. Восстановление меню — отдельная backend-задача; здесь не описываем будущую автоматику как готовую. Не добавлять кнопку восстановления или другую backend-функцию. Удалить «После выхода меню снова доступно.» целиком.

## Состояния и переходы

| Состояние | Верхняя строка | Пояснение / Win-действия | CaptureField | Переключатели |
|---|---|---|---|---|
| Установлен и доступен | Статус моста, чип, выбор другой | Видны | Скрыт в idle | Видны, enabled по мосту |
| Установлен, временно недоступен / ошибка / отключён политикой Cowork | Реальный commandStatus, не заменять фиктивным ready | Видны; повторная проверка остаётся | Только при command captureState != idle | Существующая логика enabled, без новых обещаний |
| Cowork не установлен, настройки | Статус «Astra Cowork не установлен», чип, disabled «Выбрать другую» | Пояснение и Win-кнопки скрыты; видна отдельная ghost «Проверить снова» в x=14, через 8 px после top | Скрыт в idle | Обе видны, disabled, opacity=1 |
| Cowork не установлен, мастер | Весь command editor скрыт, высота 0 | Скрыты | Скрыт | Не предусмотрены в мастере |
| capturing / captured | Верхняя строка и статус остаются | Остаются видимыми | Под действиями; существующее приглашение, отмена и обработка клавиш | Настройки остаются ниже поля |
| success / conflict / duplicate / not-grabbed | Не скрывать действующую клавишу | Сохраняются | Все существующие сообщения, свободные кандидаты и действия; текст переносится по внутренней ширине | Настройки остаются ниже поля |

Переходы: «Выбрать другую» → beginCommandCapture → capturing → captured → существующий success/error; Esc или отмена → cancelCapture → idle. «Левая/Правая Win» меняют commandHotkey, «Проверить снова» вызывает refreshCommandStatus; результат показывает существующий commandStatus. Это оформление уже имеющихся действий; новый polling/loading/backend не вводится. Пока refresh не сообщает отдельного pending-состояния, не рисовать выдуманный спиннер.

## Клавиатура и UX-проверка

Порядок Tab сохраняет визуальный порядок: «Выбрать другую» → «Левая Win» → «Правая Win» → «Проверить снова» → видимые действия CaptureField → переключатели в настройках. Скрытые / disabled контролы не участвуют. Фокус CaptureField и Esc сохраняются по существующему контракту; Tab не перехватывать новым Shortcut. Для фокус-кольца Theme: 2 px, зазор 2, радиус 8; поля 14/7 оставляют кольцу место. Шрифт PT Root UI, клавиша PT Mono; цвет не является единственным признаком ошибки. Тёмная тема заменяет цвета теми же токенами, геометрия идентична.

Независимый design_reviewer сравнивает render реализации с SVG и правилами выше:

- Полная карточка настроек при окнах 900 и 1035: outer W=672/796, текст/кнопки/capture x=15 относительно рамки; верхние и нижние подписи на этой же линии. Нет прижатых к рамке элементов.
- Между top/пояснением/действиями gap=8, после последнего элемента 7; нет двойного паддинга у SettingRow. Переключатели остаются прежнего размера и высоты строк.
- Мастер при обеих ширинах: W=580, inset14; no-Cowork занимает 0 px; нижние переключатели не появляются. Capture растёт по содержимому и доступен при прокрутке.
- Проверить installed/uninstalled, capturing, conflict, duplicate, not-grabbed и длинный commandStatus; подписи, сообщения и кольца фокуса не обрезаются. Повторная проверка доступна в настройках без Cowork.
- Светлая и тёмная темы: тексты читаемы, disabled не полупрозрачный; сравнивать линии рамки/выравнивания, не рендеринг отдельных глифов между SVG и Qt.
- Подтвердить отсутствие ложного обещания автоматического возврата меню и новых функций backend.

Сам target не доказывает работу Win, KDE/Fly, микрофона, живого захвата, доступность screen reader или прохождение сценариев реализации. Эти проверки здесь не выполнялись.
