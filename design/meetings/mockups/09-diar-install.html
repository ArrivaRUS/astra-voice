ГдеЧто
Порядок Tab, раздел… → переключатель «Разделять собеседников по голосам» → кнопка строки (Установить / Отмена / Повторить / Переустановить) → поле «Как подписывать вас» → …
Порядок Tab, карточка«Сохранить как…» → «⋯» → кнопка строки разделения → таблица реплик
Кнопка «Установить»имя «Установить модели для разделения по голосам, 34 МБ»; Enter / Пробел
Кнопка «Отмена»имя «Отменить установку моделей разделения»; Esc установку не отменяет
Кнопка «Повторить»имя «Повторить установку моделей разделения», описание — текст ошибки
Полосароль ProgressBar, имя «Установка моделей разделения», значение 0–100
Текст строкиStaticText; при ошибке и при успехе — AlertMessage (как UpdatePanel), читается один раз
Фокус после итогакнопка сменила текст — фокус остаётся; кнопка исчезла — раздел: переключатель выше; карточка: таблица
Окна нарисованы по высоте содержимого; в продукте — 1024×620 / 900×588 и прокрутка. Подсветка фокуса (кольцо) показана на одной кнопке в плитках «Скачивание», «Отменено», «Ошибка: нет сети».
