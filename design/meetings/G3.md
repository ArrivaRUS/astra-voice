## Ключевые числа (из `tokens.md`, канон — токены, не макет)

- Окно настроек: 1024×620 (минимум 900×588), сайдбар 184, контент с отступами 22, StatusBar 36 — без изменений.
- Карточка встречи A: таблица реплик колонки **76 / 124 / остальное**; панель «Участники» **232**; при контенте < 760 px —
  полоса над таблицей + выезжающая панель **300**; номер спикера — нейтральный кружок у каждой реплики и в панели.
- Плашка записи W2 (поверх окон, `PillTheme`, сверху по центру): постоянный ряд **36**, ширина **340–524**, второй ряд с
  отступом 22, радиус двухрядной 14, высота 63.8–120; свёрнутая ≈ 141.6; все действия плашки дублируются в меню трея.
- Окно старта W4: ширина **460**, высота по содержимому 371–523 (рабочий предел 565, абсолютный 600).
- Экран ответственности D1: высота ≤ клиентская − 48 (540 / 508), шапка и кнопки закреплены, тело прокручивается.
- Тост: одна строка, ширина ≤ контент − 44 (752 / 628), высота 32.8 / 42.8, радиус 8, своя тень (новый компонент `toast*`).
- Кнопки: малая 28.1, квадратные «⋯»/плеер **28×28** в строках и **34×34** в шапке; danger = secondary + красный текст.
- Глифы для `icons.py`: **22 новых** (встреча, запись, пауза, стоп, чат, объединить, ИИ, гарнитура, динамик,
  collapse/expand, chevl, …) — контуры в `tokens.md` §8.2.

  Решение «режим заливки в `icons.py` или контурная перерисовка» — в бриф двойного архитектора E13.
