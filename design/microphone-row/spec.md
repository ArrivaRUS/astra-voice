## Состояния и переходы

- Normal: известная громкость и нет mute → select,slider,%,доступная sound button в основной линии. Low<30 дополнительно показывает Поднять, canRestore — Вернуть, оба на той же оси.
- Unknown: громкость−1 → slider/% скрыты; их зарезервированный участок можно сохранить для стабильности основного ряда. Текст «Не удалось узнать громкость микрофона» вынести под основную линию; в основной линии остаётся sound button при canOpenSoundSettings. Не показывать фиктивные0 %/100 %.
- Muted: скрытый slider/%; Поднять при существующей capability остаётся на основной линии; сообщение «Звук микрофона выключен в системе — вас не слышно» ниже. Включение/успех действия переводят в соответствующее реальное состояние моста без изменения общей оси.
- Unavailable: отсутствие контроля громкости не убирает доступное системное действие звука. canOpenSoundSettings определяет видимость этой кнопки независимо от canRaiseMic. Отсутствие capability не означает отсутствие микрофона. Не придумывать loading/error/empty по значениям capability. Неполученные данные до подключения моста — существующий fallback, без спиннера и системных вызовов.
- Empty device list: сохраняется существующий «Системный по умолчанию», не объявлять автоматически «Микрофон не найден». Установленный факт ошибки приходит из моста.
- Error: существующий micError NoteBanner над группами остаётся; сообщение не помещать между основными контролами. Повторное чтение/успех восстанавливают состояние по мосту. Длинные сообщения wrapWord в доступной ширине, без обрезки.
- Locked device: select disabled, значение видно; «Задано администратором» с замком сохраняется явно. При необходимости место под бейдж — отдельная дополнительная линия внутри той же настройки, выровненная x15; main axis не сдвигать относительно своих контролов. При наличии status текст идёт следующей строкой. Policy не блокирует sound action автоматически; полномочия кнопок сохраняются по существующим predicates. Не переносить бейдж на сквозной SettingRow всех экранов.

Вторичный текст занимает только нужную высоту с gap4 после основной линии и существующим шрифтомsub12; переносы считаются по фактической ширине. Важно: центр label не вычислять от высоты этой дополнительной области. Пояснение о фактически открытом устройстве по design/spec§3.2 не является задачей этой правки.

## Клавиатура и независимая проверка

Tab: selector→slider при видимости→Поднять→Вернуть→Настройки звука; скрытые и disabled пропускаются, декоративные label/% не получают фокус. Использовать существующие keyboard/focus-ring компоненты; для slider сохранить Accessible.name «Громкость микрофона», step5 и стандартные клавиши. Esc закрывает select popup; Tab не перехватывать новым Shortcut. Focus ring полностью в карточке/viewport. Браузер/внешний системный звук в этой проверке не запускать.

До приёмки независимый reviewer сравнивает actual PNG полной карточки и соседних строк в light/dark: полная матрица состояний при scale1, окна900×588 и1035×588 logical px; при scale1.25/1.5 — представительные normal100 и low20 с canRestore в минимальном окне900×588. DPI масштабировать на уровне Qt, не уменьшать контролы для умещения. Ширина900 относится к logical units, физическая при1.5 —1350. Проверить normal100/low20 с canRestore,unknown,muted с canRestore,locked варианты,canRaise=false/canOpen=true,оба capability=false. Длинное имя устройства/popup, длинная micError, ранний/поздний bridge, unknown→normal→muted→unknown, resize/hide/show.

Обязательные assertions: единый centerY≤1; все видимые primary controls находятся на этой оси и внутри карточки; label полный; ни кнопка ни процент не elide; gap≥8; минимум selector120/slider80; отсутствие overlap и QML warnings/binding loops; % reserve не сдвигает neighbours при0/100; нижние сообщения не сдвигают axis label относительно main controls. Старый тест проверяет лишь label.centerY≤selector.bottom, что допускает текущий дефект: заменить на точное centerY сравнение всего ряда.
