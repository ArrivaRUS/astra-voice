Полный макет — направление A «Панель»
24 экрана × 2 темы = 48 файлов · окно 900×620 (оно же минимальное) · QtQuick Controls 2 (Qt 5.15) · ⛔ G3

Что здесь

Развёрнутое направление A «Панель», принятое на ⛔ G2 (decisions/log.md, 2026-09-08). Каждый экран — самодостаточный HTML без внешних ресурсов и скриптов; светлая и тёмная тема сделаны для всех экранов, потому что тема читается из kdeglobals и меняется на лету.

Решения заказчика, зашитые в макет: пилюля резиновая под текст (172 → 320 px, без многоточия), каталог моделей показывается целиком с прокруткой, подтверждение «Готово» — 500 мс. Решения 2026-09-08: окно 900×620 — минимальный размер, «Проверить обновления» в трее активен всегда, тумблера VAD в v1 нет, «отечественная» определяется по юрлицу правообладателя. Цифры каталога — из research/catalog-numbers.md, заглушек не осталось. Поведение и микрокопия — из design/flows.md, состав и цифры — из PRD.md F1–F16 и §7.2.

Что потребует кастомного QML

Для архитекторов: список мест, где QtQuick Controls 2 «из коробки» не хватает. Оценка — относительная трудоёмкость, не часы.

Пилюля-оверлей
Frameless-окно поверх всех: Qt.Tool | Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.WindowDoesNotAcceptFocus, вне Alt+Tab, без активации. В QtQuick Controls 2 такого компонента нет — отдельный QQuickWindow с собственной геометрией и повторной проверкой перекрытия (урок Astra Cowork: KWin теряет StaysOnTop при смене раскладки).
дорого
Столбики уровня (9 полос, ~30 кадр/с)
Ни ProgressBar, ни Slider не годятся: нужна перерисовка по аудиофрейму. Canvas или лёгкий Repeater из Rectangle с биндингом на свойство уровня; выбор — по замеру CPU (пилюля не должна греть машину во время диктовки).
средне
Резиновая ширина пилюли
implicitWidth = max(172, textWidth + отступы), потолок 320, без elide, содержимое по центру. Пол в 172 px обязателен: без него «Готово» даёт 83 px, «Отменено» 105 px, и окно дёргается в последовательности слушаю (188) → распознаю → готово. Анимация ширины — Behavior on implicitWidth.
средне
Карточка модели
Композит: два трека метрик с текстовым значением, до двух бейджей по приоритету, нижняя строка тегов, прогресс-полоска и переменный набор кнопок на 20 состояний. Проще всего — один QML-компонент с state-машиной, а не ветвление в делегате списка.
дорого
Поле захвата комбинации
Захват «сырых» нажатий мимо focus-цепочки QML: нужен нативный event-filter (X11 XGrabKeyboard на время захвата) плюс чтение kglobalshortcutsrc для имени конфликтующего действия KDE.
дорого
Сегментированный переключатель
В Controls 2 нет SegmentedControl: собирается из Row + два AbstractButton c общим фоном; важно, чтобы Tab обходил его как один элемент.
дёшево
Тумблер с состоянием «заблокировано администратором»
Switch + значок замка + подпись; визуально «выключен», но не серый-невидимый — контраст подписи ≥ 4,5:1.
дёшево
Трей и меню
QSystemTrayIcon + QMenu — это Widgets, а не QML: приложение получается гибридным (QQmlApplicationEngine + QWidgets-трей). Значок — SVG из лого-пака, цвет несёт только третья точка.
средне
Подсказка «Как мы считаем»
ToolTip в Controls 2 не принимает клики — нужен Popup с closePolicy и ссылкой внутри.
дёшево
Цифры моноширинно
font.features (tabular-nums) появился в Qt 6.7; в Qt 5.15 проценты, скорость и версии набираем PT Mono, иначе полоска прогресса «дёргается».
дёшево
Тема из kdeglobals до первой отрисовки
Палитра читается парсером ini на старте (до engine.load) и живёт синглтоном; Qt-палитра в процессе оверлея врёт про тему — проверено на Astra Cowork.
средне
Окно polkit
Не наше окно: pkexec/PolicyKit-агент KDE. Наша зона — ровно один вызов за установку и корректная обработка отказа.

Замечания к PRD и flows.md

Расхождения, найденные при разворачивании макета. Правки в flows.md уже внесены; правки в PRD — за product-manager.

PRD F3.2 — «Готово» 500 мс✅ Уже синхронизировано: PRD F3.2 поправлен (коммит 8a0bcb9), таблица состояний в design/flows.md §3 обновлена этой же правкой. В макете везде 500 мс.
flows.md §8 — вопросы на приёмкуПункты 2–4 закрыты решением G2 (резиновая пилюля, каталог целиком, 500 мс). Пункт 1 (выбор направления) закрыт выбором A. Раздел можно свернуть в «решено».
Лицензия в decisions/log.mdЗапись от 2026-09-07 говорит «MIT — предварительно», а PRD F13, HEARTBEAT и файл LICENSE в репозитории — GPL-3.0-or-later. В макете «О программе» стоит GPL-3.0-or-later; старую запись стоит пометить как замещённую.
Цифры каталога✅ Закрыто 2026-09-08: все 12 позиций взяты из research/catalog-numbers.md — размер как сумма точных байт файлов рантайма (HF API, десятичные МБ), WER по Russian LibriSpeech и RTFx из столбца x64 int8. Заглушек в макете больше нет. Правки затронули 9 из 12 размеров (в PRD были МиБ, записанные как МБ) и 10 из 12 значений WER. Требуется ревизия PRD §7.2 — за product-manager.
Whisper small — единственная позиция без цифрПо протоколу §7.1 замеров нет ни для WER, ни для RTFx. В макете полоски пунктиром и подпись «нет данных», в карточке — пояснение «FLEURS 11,4 %, другой набор; замерим на вашем компьютере». Собственный замер — v0.2 (US-5.4).

Доступность (§8 PRD)

  • Контраст текста ≥ 4,5 : 1 в обеих темах; для «выключенных» элементов введён отдельный токен --fg-dis (#67748B / #8C97AC) вместо прозрачности — прозрачность давала 2,1 : 1.
  • Ни одно состояние не передаётся только цветом: у ошибки треугольник и подпись, у предупреждения — треугольник и жёлтый фон, у записи — столбики уровня, у готовности — галочка. В трее состояние дублируется подсказкой при наведении.
  • Бирюза #12B3A0 — только «слушаю» и только как графика; для текста берётся #0B7F71 (светлая) / #2FD9C4 (тёмная).
  • Все действия достижимы с клавиатуры; видимая рамка фокуса 2 px в цвете --primary. Esc отменяет захват комбинации и закрывает панели.
  • Цифры (проценты, скорость, версии, задержки) — PT Mono: в Qt 5.15 нет tabular-nums.

Как собрать заново

cd design/mockups/final && python3 _build.py — генераторы _shell.py (оболочка, палитра, данные каталога), _p1.py (Общие, Модели), _p2.py (Вывод, Сеть, Продвинутые, О программе, Отладка), _p3.py (онбординг, пилюля, трей, диалоги). Базовые компоненты и палитра переиспользуются из ../directions/_base.py — правки цвета и геометрии делать там.
