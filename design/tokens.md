Этот файл — **словарь значений**, а не новый дизайн. Каждое число взято из кода генераторов
макета или из `brand-basics.md`; в JSON у каждого токена есть поле `src` вида `файл:строка`.
Где значение в источниках отсутствует — стоит `value: null` и пометка; такие места собраны
в разделе «Открытые вопросы». **Ничего не придумано «на глаз».**

**Как сверялось с рендером.** CSS-значения извлечены из генераторов; геометрия компонентов
дополнительно **измерена в реальном рендере**:
`chromium --headless=new --dump-dom` над пробной страницей, собранной теми же функциями
`_base`/`_shell`, со скриптом `getBoundingClientRect()` + `getComputedStyle()`.
Так получены реальные высоты кнопки (33,5 px), пункта сайдбара (34,3 px), пилюли (36 px)
и ширина блока столбиков уровня (78 px) — они не выводятся из CSS в одну строчку.

**Как читать JSON.** Лист словаря — объект `{"value": …, "src": "файл:строка", "note": …}`.
Генератор темы берёт `value`; `src` нужен, чтобы проверить значение, а не поверить на слово.
Ссылки на другие токены записаны их именами (`"fg-muted"`, `"primary"`), а не hex —
разворачивать при генерации.

`size.window-min-h = 588`, а `900 × 620` из спеки §1.2 — размер **с декорацией**.

## 5. Компоненты: размеры и состояния

Полные значения — в `component.*` JSON. Здесь — то, что чаще всего понадобится.

### 5.0 Состояния: единый принцип (`state.*`)

Решение Юрки (`decisions/log.md`): **hover — поверхность на ступень, pressed — ещё ступень,
focus — кольцо 2 px акцентом снаружи с зазором 2 px.** Один принцип на все интерактивные
поверхности: кнопка, пункт сайдбара, пункт меню и списка, карточка модели, селект, чип, сегмент.

| Роль | Светлая | Тёмная | Комментарий |
|---|---|---|---|
| `hover-on-surface` | `#EDF1F7` (= `bg-surface-2`) | `#232C3C` (= белый 6 % поверх `surface`) | ступень от белой поверхности |
| `pressed-on-surface` | `#E7ECF4` (= `bg-titlebar`) | **`#252E3E`** (= белый **7 %**) | вторая ступень |
| `hover-on-surface-2` | `#E7ECF4` | `#141924` (= белый 5 %) | сайдбар, трей-меню |
| `pressed-on-surface-2` | `#DDE3EE` | `#1E232D` (= белый 9 %) | сайдбар, трей-меню |
| `primary-hover` | `#19356A` (−8 %) | `#789CEA` (+8 % к белому) | заливка primary-кнопки |
| `primary-pressed` | `#173263` (−14 %) | `#8AACF0` (+14 %) | — |
| `focus-ring` | **`#0A776A`** | `#2FD9C4` | кольцо 2 px, зазор 2 px, радиус 8 (У1 принято) |
| `disabled` | только `fg-disabled` | только `fg-disabled` | **никакой `opacity`** |

В светлой теме обе ступени взяты из уже существующей нейтральной лестницы палитры
(`#FFFFFF → #EDF1F7 → #E7ECF4 → #DDE3EE`) — новых оттенков не заведено.
В тёмной ступень идёт **вверх** по светлоте: буквальный `bg-surface-2` там темнее фона окна
и читался бы как «утоплено», а не «под курсором».

## 9. Маппинг «токен → QtQuick Controls 2»

Целевая форма — синглтон `Theme.qml` (`pragma Singleton`), генерируемый из `tokens.json`.

| Группа токенов | Как выразить в QML |
|---|---|
| `color.light.*` / `color.dark.*` | `readonly property color bgApp: dark ? "#0B1220" : "#F7F9FC"` — одно свойство на семантическую роль, ветвление по `Theme.dark` |
| Переключение темы | `property bool dark` — читать из `~/.config/kdeglobals`, **не** из Qt-палитры: в процессе оверлея палитра врёт (урок Astra Cowork) |
| `color.*.primary` + `primary-fg` | `palette.highlight` / `palette.highlightedText` у корневого `ApplicationWindow`; для кнопок — прямые `Theme.primary` в `background`/`contentItem` |
| `color.*.fg` / `fg-secondary` / `fg-muted` | `palette.windowText` / свои `Theme.fgSecondary`, `Theme.fgMuted` — в стандартную палитру Qt эти роли не ложатся |
| `color.*.fg-disabled` | **не** `enabled: false` + `opacity`, а явный `color: control.enabled ? Theme.fg : Theme.fgDisabled`; opacity в макете снята намеренно |
| `color.*.border` | `border.color` у `Rectangle` в `background:`; `border.width: Theme.borderHairline` |
| `color.fixed.*` | отдельный синглтон `PillTheme.qml` — эти цвета **не** переключаются с темой |
| `font.family.ui` / `.mono` | `FontLoader` не нужен (шрифты системные): `font.family: "PT Root UI"`, `font.family: "PT Mono"`; резервный стек задаётся через `Qt.font({family: "PT Root UI, PT Astra Sans, ..."})` или `QFont::setFamilies()` в C++ |
| `font.role.*` | `readonly property font h2: Qt.font({family: ui, pixelSize: 20, weight: Font.Bold})`; интерлиньяж — `Text.lineHeightMode: Text.ProportionalHeight; lineHeight: 1.25` |
| Веса 400/500/700 | `Font.Normal` / `Font.Medium` / `Font.Bold` |
| `space.*`, `size.*` | `readonly property int windowContentX: 22` и т. д.; в `Layout.margins`, `spacing`, `implicitWidth` |
| `radius.*` | `Rectangle { radius: Theme.radiusCard }`; `radius.circle` → `radius: width / 2`; `radius.appicon` (22 %) → `radius: width * 0.22` |
| `border.focus` + `color.*.focus-ring` | `Rectangle { visible: control.visualFocus; anchors.margins: -Theme.focusOffset; border.width: 2; border.color: Theme.focusRing; radius: 8; color: "transparent" }` |
| `shadow.*` | в Qt 6 — `MultiEffect { shadowEnabled: true; shadowBlur; shadowVerticalOffset; shadowColor }`; в Qt 5 — `DropShadow` из `QtGraphicalEffects`. Значение `0 14px 44px` → `shadowVerticalOffset: 14`, `shadowBlur` подбирается (44 px CSS ≈ blur 0.5–0.6 в `MultiEffect`) — **требует калибровки на глаз в реальном окне** |
| `motion.duration.*` | `Timer { interval: Theme.pillDone }`; переходы — `Behavior on … { NumberAnimation { duration: … } }` |
| `motion.easing` | **не задано** — до ответа человека брать `Easing.OutCubic` как нейтральный дефолт и не считать это токеном |
| `component.pill.*` | отдельное `Window { flags: Qt.Tool \| Qt.FramelessWindowHint \| Qt.WindowStaysOnTopHint \| Qt.WindowDoesNotAcceptFocus }`; ширина — `implicitWidth` содержимого, `Math.min(320, Math.max(172, …))`, **без `elide`** |
| `component.pill.bar-formula` | `Repeater { model: 9; Rectangle { height: Math.max(3, Math.round(level[index] * 20)) } }` |
| `icon.*` | SVG через `Image { source: "qrc:/icons/cog.svg"; sourceSize: 16 }` + `MultiEffect { colorization }` для перекраски, либо иконочный шрифт. `currentColor` в QML не работает — цвет задаётся снаружи |
| `zindex.*` | `z:` у элементов внутри одной сцены; диалоги — `Popup`/`Dialog` (свой слой), подсказки — `ToolTip` |

Практическая рекомендация: генерировать `Theme.qml` **скриптом из `tokens.json`**, а не
переписывать руками — иначе первая же правка макета разъедется с кодом.
