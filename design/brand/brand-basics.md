## 1. Бренд-бриф (короткий)

**Имя. `Astra Voice`** — латиницей, в одно слово с пробелом, оба слова с прописной.
Пакет и репозиторий — `astra-voice`. Кириллическая форма («Астра Войс») официально
**не используется**: если понадобится для документов и госзакупок — заводится отдельным
решением, а не по ходу. Товарный риск по марке «Астра» (принадлежит ГК «Астра»)
заказчику предъявлен и **принят им 2026-09-07**; перед публикацией репозитория и
регистрацией знака нужна проверка юристом.

**Суть.** Зажал клавишу — сказал — текст появился там, где стоит курсор. Полностью офлайн,
на процессоре, по-русски, за доли секунды.

**Тон.** Современный, спокойный, точный. Дружелюбный без сюсюканья. Инструмент, которому доверяешь.

**Аудитория.** Сотрудники корпораций и госструктур на Astra Linux SE, которые много пишут —
письма, документы, чаты. Не гики: интерфейс должен быть понятен без документации.

**Ассоциации.** Речь → текст · скорость · приватность (ничего не уходит наружу) · точность ·
лёгкость · русский язык как первоклассный (ё, пунктуация).

**Анти-референсы.** Клипарт-микрофон · «сириподобные» радужные шары · копии Google/Apple/Microsoft ·
айдентика Handy · мультяшность · градиентная «AI-магия» образца 2023 года.

**Соседство с ОС.** Айдентика должна выглядеть «своей» рядом с Astra Linux: тёмно-синяя база,
плоские формы, PT-шрифты. При этом **логотип и марка ГК «Астра» не используются**, оранжево-коралловый
акцент Астры не копируется — у продукта свой сигнальный цвет.

## 2. Палитра

Все значения проверены на контраст (WCAG 2.1). Приведены отдельные «текстовые» варианты там,
где основной оттенок слишком светлый для подписи.

### 2.1 Ядро бренда

| Роль | Токен | Hex | Где | Контраст |
|---|---|---|---|---|
| Основа, знак, текст | `brand.ink` | `#0E1729` | знак на светлом, заголовки | 17.9 : 1 на белом |
| Первичный (кнопки, ссылки) | `brand.primary` | `#1B3A73` | primary-кнопка, активные пункты | 11.1 : 1 на белом |
| Первичный hover | `brand.primary.hover` | `#12294F` | | |
| **Акцент** (сигнальный цвет продукта) | `brand.accent` | `#12B3A0` | знак, индикатор «слушаю», прогресс | 2.6 : 1 — **только графика, не текст** |
| Акцент для текста/иконок | `brand.accent.ink` | `#0B7F71` | подписи акцентом на светлом | 4.9 : 1 |
| Акцент светлый | `brand.accent.300` | `#3FCDBB` | подсветки, hover | |
| Акцент-подложка | `brand.accent.bg` | `#E3F7F4` | плашки, выделение распознанного | |

Почему бирюза: она держит семейное родство с тёмно-синей базой Астры, но не повторяет её
коралловый акцент; и, в отличие от красного/оранжевого, не конфликтует с состояниями
«ошибка» и «запись».

> **Решено 2026-09-07.** Бирюза `#12B3A0` (в тёмной теме `#2FD9C4`) — фирменный цвет
> состояния **«слушаю»**. Альтернативы (янтарь, красный как «идёт запись») сняты:
> янтарь занят под «распознаю», красный — под ошибку. Это единственный цвет, которым
> продукт сигналит «микрофон открыт»; больше он ни за что не отвечает.

### 2.4 Состояния голосового ввода

Ключевая вещь для трея: **форма иконки одна и та же, меняется только цвет** (в C3 — цвет точки
внутри клавиши). Так пользователь читает состояние боковым зрением, а иконка не «прыгает».

| Состояние | Светлая | Тёмная | Поведение |
|---|---|---|---|
| Покой | `#5A6884` (или `currentColor` темы KDE) | `#8C97AC` | символьная моно-иконка, без анимации |
| **Слушаю** (клавиша зажата) | `#12B3A0` | `#2FD9C4` | мягкая пульсация 1.2 с, без мигания |
| **Распознаю** | `#E8A33A` | `#F2B559` | статичный цвет, без пульсации |
| Готово (0.8 с) | `#2FA36B` | `#4FBF88` | короткая вспышка, затем покой |
| Ошибка | `#D64545` | `#F0645F` | статично до следующего нажатия |

Текстовые варианты семантики на светлом: успех `#1F7D50` (5.1 : 1), предупреждение `#8F5E12`
(5.6 : 1), ошибка `#C0322F` (5.6 : 1). Цвет **никогда не единственный носитель смысла** —
рядом всегда подпись или изменение формы (требование доступности и госсектора).

## 3. Типографика

Проверено `fc-list` на целевой машине (ALSE 1.8.5) — **все три семейства уже установлены**,
тянуть шрифты в deb не нужно, достаточно зависимостей пакета:

| Роль | Семейство | Пакет | Начертания |
|---|---|---|---|
| Интерфейс и заголовки | **PT Root UI** | `fonts-pt-root-ui` | Light / Regular / Medium / Bold |
| Системный запасной | **PT Astra Sans** | `fonts-pt-astra` | штатный шрифт ALSE |
| Моно (хоткеи, размеры моделей, цифры) | **PT Mono** | `fonts-pt-mono` | Regular / Bold |

Стек:

```css
--font-ui:   'PT Root UI', 'PT Astra Sans', 'Open Sans', 'Roboto', sans-serif;
--font-mono: 'PT Mono', 'DejaVu Sans Mono', 'Liberation Mono', monospace;
```

Почему PT Root UI: рисован под интерфейсы, отличная кириллица (включая «ё»), свободная лицензия
SIL OFL, уже стоит в системе и даёт семейное сходство с соседним продуктом заказчика (Astra CoWork).
Inter/Manrope/Golos UI на целевой машине **не установлены** (Inter есть в apt как `fonts-inter`,
но это лишняя зависимость ради того же результата).

### Шкала (десктоп-приложение, плотнее веба)

| Роль | Размер / интерлиньяж | Начертание |
|---|---|---|
| H1 — заголовок окна | 28 / 1.2 | Bold |
| H2 — раздел | 20 / 1.25 | Bold |
| H3 — подраздел, имя модели | 16 / 1.3 | Medium |
| Body | 14 / 1.5 | Regular |
| Small — подписи, статус-строка | 13 / 1.45 | Regular |

Хоткей набирается моноширинным в «клавише»: подложка `neutral.100`, радиус 6, паддинг 2/6,
рамка снизу 2 px `neutral.200` — читается как физическая клавиша.

## 4. Правила знака

- **Векторный SVG.** Знак работает отдельно от текстовой части; текстовая часть без знака —
  только в тексте документов.
- **Текст в финальном логотипе — в кривых.** В концептах текстовая часть набрана живым шрифтом
  (`PT Root UI`), чтобы имя можно было заменить за минуту. В `logo.svg` после согласования буквы
  переводятся в контуры (`inkscape --export-text-to-path`) — иначе на машине без PT Root UI
  логотип «поедет».
- **Минимальный размер:** знак — 16 px по высоте, замок (знак + имя «Astra Voice») — **120 px**
  по ширине (имя длиннее прежнего рабочего, 96 px больше не хватает).
- **Охранное поле:** со всех сторон не меньше 25 % высоты знака.
- **Моно.** Знак обязан читаться в один цвет: «чернильные» части — `currentColor`,
  акцентные — литеральный `#12B3A0`. Моно-версия получается заменой акцента на `currentColor`.
- **Никаких CSS-переменных внутри SVG.** Проверено на этой машине: `rsvg-convert`/librsvg
  (а это GTK-миниатюры, конвертеры, часть просмотрщиков) **не поддерживает** `var(--a)` —
  `fill:var(--a)` тихо падает в чёрный, а `stroke:var(--a)` вообще **исчезает**: у концепта 03
  пропадали все три акцентных штриха, знак превращался в пустой прямоугольник. В `.svg`-файлах
  только литеральные hex и `currentColor`; тему переключаем через
  `@media (prefers-color-scheme: dark)` с явными цветами.
- **Пробел между начертаниями.** Если имя набрано двумя `<tspan>` разного веса, ставить
  `xml:space="preserve"` на `<text>`: хвостовой пробел внутри `tspan` схлопывается,
  а `&#160;` librsvg рисует нулевой шириной — в обоих случаях получается «AstraVoice».
- **Трей KDE.** Отдельный файл `concept-N-tray.svg`, 22×22, только `currentColor`, штрих 1.7–2.5 px,
  без полупрозрачности и градиентов — иначе KDE-тема перекрасит некорректно.
- **Иконка приложения.** Знак в скруглённом квадрате (радиус 22 % стороны), поля 18 % — размеры
  16 / 22 / 24 / 32 / 48 / 64 / 128 / 256 px; символьный вариант — для трея и меню Fly.
- **Нельзя:** менять пропорции и наклон, добавлять тени, обводки и градиенты, класть на пёстрый
  фон, окрашивать в цвета состояний (это привилегия трей-иконки), ставить в один замок с
  логотипом Astra Linux, использовать марку ГК «Астра» в любом виде.
