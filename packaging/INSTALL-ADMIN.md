# Установка Astra Voice администратором

Черновик вехи M1. Документ адресован администратору рабочей станции Astra Linux SE 1.8:
установка требует прав администратора, пользователь сам поставить пакет не может.

## Что вы ставите

| | |
|---|---|
| Пакет | `astra-voice_<версия>_amd64.deb`, Section `utils` |
| Размер | ~13 МБ (с движком распознавания), ~57 МБ после установки |
| Собственных ELF | **3** — библиотеки onnxruntime в `/usr/lib/astra-voice/vendor/onnxruntime/capi/`. Это те объекты, которым нужна ГОСТ-подпись в контуре с ЗПС (см. ниже) |
| Сеть при установке | не нужна, если зависимости уже есть; недостающие apt возьмёт из ваших репозиториев |
| Данные пользователя | в `$HOME`, пакет туда не пишет; `apt remove` их не удаляет |

Куда кладутся файлы: код — `/usr/lib/astra-voice/`, ресурсы —
`/usr/share/astra-voice/`, запуск — `/usr/bin/astra-voice`,
пустой каталог `/var/lib/astra-voice/staging` (`root:root`, 0700) под будущий
механизм обновления. Каталог `/etc/astra-voice/` пакет **не создаёт** —
файл политики `policy.conf` заводит администратор.

## 1. Проверка подлинности — до установки

Вместе с пакетом публикуются `SHA256SUMS` и отсоединённая подпись `SHA256SUMS.asc`.

```sh
# 1. Отпечаток ключа, которым подписан релиз, должен совпадать с опубликованным
gpg --show-keys --fingerprint release.gpg

# 2. Подпись файла сумм
gpgv --keyring ./release.gpg SHA256SUMS.asc SHA256SUMS

# 3. Сумма самого пакета
sha256sum -c --ignore-missing SHA256SUMS
```

`gpgv` должен напечатать `Good signature`. Отпечаток ключа:

```
<TODO: отпечаток мастер-ключа заказчика — подставляется вместе с генерацией
ключа, docs/SECURITY.md §4. В сборках вехи M1 используется ТЕСТОВЫЙ ключ
CB95 1AD7 9440 7972 A0B1  A5BB AFA8 7398 C495 3A71 — на такие сборки полагаться нельзя.>
```

Ключ берётся из документации проекта или из `/usr/share/astra-voice/data/keys/release.gpg`
уже установленного пакета, **но не из того же каталога, что и проверяемый файл**.

## 2. Установка

```sh
sudo apt install ./astra-voice_<версия>_amd64.deb
```

`apt` (а не `dpkg -i`) — чтобы зависимости доехали из ваших репозиториев.
В офлайн-контуре:

```sh
sudo apt-get install --no-download --no-remove ./astra-voice_<версия>_amd64.deb
```

Если apt сообщит о недостающих пакетах — их нужно занести в контур обычным
порядком; список зависимостей виден командой
`dpkg-deb --field astra-voice_*.deb Depends`.

Проверка после установки:

```sh
astra-voice --version
```

## 3. Настройка политики (необязательно)

`/etc/astra-voice/policy.conf` — INI-файл, читается только если владелец `root`
и права не дают записи группе и остальным. Он задаёт профиль (`profile=secure`
отключает всю сеть), корпоративный каталог моделей, разрешение на обновления.
Пример — `/usr/share/doc/astra-voice/examples/policy.conf` (появится в вехе M10).

Файла нет — работают значения по умолчанию. Файл есть, но невалиден — утилита
переходит в безопасный режим, а не игнорирует политику.

## 4. Контур с замкнутой программной средой (ЗПС)

При включённой ЗПС (`DIGSIG_ELF_MODE=1`) исполняемые объекты обязаны нести
ГОСТ-подпись. У этого пакета таких объектов **три** — библиотеки onnxruntime,
перечисленные выше и в `sbom.cdx.json` с их sha256. Процедура подписи —
средствами организации (`bsign-integrator`, ключ организации) — планируется к v1.1.

Ограничение, о котором честно: если поверх ЗПС включена блокировка
интерпретаторов, продукт не работает — он написан на Python и запускается
`/usr/bin/python3`. Обходного пути нет.

Встроенный механизм обновления в таком контуре сам себя отключает: он проверяет
`/etc/digsig/digsig_initramfs.conf` и отказывается ставить пакет, который
организация не подписала. Обновления в этом случае — только вашими руками.

## 5. Удаление

```sh
sudo apt remove astra-voice        # программа
sudo apt purge astra-voice         # + системные файлы пакета
```

Модели и настройки остаются в домашних каталогах пользователей:
`~/.config/astra-voice`, `~/.local/share/astra-voice`, `~/.local/state/astra-voice` —
удалять их (или нет) решает пользователь.

## 6. Что утилита делает в сети

Четыре обращения, все отключаются политикой; ни звук, ни текст не передаются.
Подробно — `/usr/share/doc/astra-voice/PRIVACY.md`.
