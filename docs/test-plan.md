## Critical fixtures
- **Тестовый wav «Проверка связи»**: `data/test/test-ru-6s.wav` — «Проверка связи, запятая, всё работает точка», 16 кГц mono s16le, 6 с; `smoke_test.expect_any = ["проверка", "связи"]`; плюс `test-ru-20s.wav` (отмена), `test-ru-130s.wav` (лимит 120 с), синтетический wav с паузами (VAD), тишина 3 с, маркерная фраза «ГЕЛИОТРОП-7» (T-13).
- **Фейки процессов**: `FakeAudioSource` / `WavFileSource`; `FakeEngine` (в т. ч. возвращающий `"ls\n rm -rf ~"`, ESC-последовательность, `C-o`, `text` 50 МБ); эхо-воркер и воркер с кадром 2 ГиБ/чужим `utterance_id` для супервизора (T-21).
- **HTTP fault-server** (локальный, `tests/fixtures/http_faults.py`): 200/206 с корректным и битым `Content-Range`/304/403/404/407/429 (`Retry-After`, `RateLimit`)/таймаут/обрыв/подмена байтов/`size+1`/302 на `https://evil.example`/6 редиректов/ловушка `Authorization` для `.netrc`; фейковый HF `refs` (изменилась ветка-вариант · только `main` · без `x-repo-commit`) и GitHub `releases/latest` (`tag_name` вариации); зеркала с разными байтами.
- **Chroot для помощника**: каталог с `usr/bin/{gpgv,apt-get,dpkg-deb,dpkg}` — фейки, вызываемые **по абсолютным путям** (PATH помощник игнорирует); фикстуры `policy.conf` (нет / personal / secure / `updates=admin` / `offline` / 0666 / владелец ≠ root / symlink / невалидный), `digsig_initramfs.conf` (`DIGSIG_ELF_MODE=0|1` / нечитаем), staging (0700 root / symlink / 0755 / чужой владелец), удержанный `/var/lib/dpkg/lock-frontend`, второй экземпляр помощника.
- **Ключи**: тестовый GPG keyring — мастер + S1 + S2 + чужой ключ + ключ из `REVOKED_FINGERPRINTS` + просроченный; подписанные `SHA256SUMS` (корректный · старая версия · две строки на одно имя · имя ≠ ожидаемой версии); манифесты (валидный · меньший `serial` · без `generated_at` · дубли ключей JSON · повторы `id`/`path` · `revoked[]` активной ревизии · `purpose.ru` с HTML · `source_url=javascript:` · 1 МиБ + 1 байт); `trust.json` с `trust_epoch` больше/равно/меньше и подписью не мастером; корпоративный `catalog_pubkey` (для T-31).
- **Вредоносные ONNX**: `external_data.location="../../secret.bin"` (файл рядом, вне каталога ревизии); лишний файл в каталоге ревизии; тензор 8 ГиБ (генерируется на лету); custom-op домен.
- **Окружение**: `kdeglobals` (Breeze / BreezeDark / AstraDark), `~/.fly/paletterc` (AstraLight / AstraDark / generated-*), `kglobalshortcutsrc` (реальный, 23 КБ), `keyshortcutrc` + `ru.miscrc`, `~/.config/autostart/*.desktop` (наш · чужой с `Exec=/tmp/evil` · `handy.desktop`), env-наборы (`XDG_RUNTIME_DIR` пуст, `HF_ENDPOINT`, `HF_HUB_OFFLINE=1`, `HTTPS_PROXY=http://u:p@proxy`, `QT_QUICK_CONTROLS_STYLE=org.kde.desktop`, `PYTHONPATH`/`LD_PRELOAD`/`GNUPGHOME`).
- **Виртуальный микрофон** (машина): `module-null-sink av_test` + `module-remap-source av_test_mic` + `paplay --device=av_test` — `scripts/e2e/virtual_mic.sh up|down`; отключённый физический микрофон и `*.monitor` «по умолчанию» (T-35).
- **Пакеты**: `astra-voice-spike` 0.0.1/0.0.2 (S2); `astra-voice` `0.2.0~rc1` → `0.2.0` (S9); подписанный **старый** deb (downgrade); deb с подменённым байтом; deb с `Package`/`Architecture` ≠ ожидаемым.
- **X11/Qt**: тестовое Qt-окно с `TextEdit` под Xvfb (вставка, фокус); второе окно (смена активного между `record.stop` и `result`); тестовый сервер `org.freedesktop.Notifications` (python-dbus) с `actions` и без; Xvfb с двумя «мониторами» (позиция пилюли, struts).

## Smoke coverage
- [ ] Happy-path: `apt install` → онбординг (скачать модель) → `Ctrl+Space` в Kate → «Проверка связи, всё работает.» вставлено ≤ 0,5 с → буфер восстановлен ≤ 200 мс → «Выход».
- [ ] CLI: `astra-voice --version` · `--debug-transcribe data/test/test-ru-6s.wav` · `--stats`.
- [ ] Второй запуск показывает первое окно; `--hidden` стартует в трей без открытия аудио (`wpctl status` без потока).
- [ ] Виртуальный микрофон → `result`; тишина → `silent`; Esc → `cancelled`; 0,2 с → тишина без ошибки.
- [ ] Каталог: 12 карточек; «Скачать» → «Проверяю…» → «Установлена · Активна»; «Выбрать» другую → «Переключаю…» → «Активна»; «Удалить» активной — disabled.
- [ ] Обновление: «Доступна версия X» → панель → одно окно polkit → «Установлено · Перезапустить», `dpkg-query -W` = X; трек B → папка с `INSTALL-ADMIN.md`, `pkexec` не вызван.
- [ ] Автозапуск: перелогин (KDE и Fly) → трей есть, окно нет, аудио не открыто.
- [ ] Тема: смена схемы → перекраска ≤ 2 с (KDE); Fly — ≤ 2 с либо подсказка «перезапустить».
- [ ] Fly: пилюля поверх `fly-term` без кражи фокуса; значок в трее панели Fly; уведомление через `fly-notifications`.
