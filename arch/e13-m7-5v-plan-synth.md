## 3. Решённые трактовки (Юрка)

1. **Выход из программы посреди повтора:** diar незавершён → при следующем запуске с начала; после `diar=done` — продолжение Д5 (бюджет не сбрасывается, Stop-and-Fix M7). Текст §Р.3 «начнётся с начала, 0 %» поправить на «продолжится; если разделение не успело — начнётся с начала» — правка UX, без изменения поведения для человека по смыслу.
2. **Повтор с частичным отказом Д5** (`diar=done`, `reconcile.failed`): публикуется, `processing_status=partial` — как у первой расшифровки сегодня. Звук держится бессрочно (как сейчас). Отдельной кнопки не добавляем в этом шаге — **вопрос в долг** (предложить «Оставить так» и для partial по Д5) — вынести на T2/владельцу вместе.
3. **Политика запретила запись/разделение** при незавершённом повторе → задание ждёт, звук удержан; при выключенном разделении к моменту допуска — повтор снимается как сбой (#1 §3.6).
4. **Старые сборки** не читают `meeting.json` с новыми ключами — допустимо (функция встреч не выпущена).
5. **Д5 поверх уже уточнённого текста** (#1 риск 3): сброс `multiple_speakers` при посеве; проверка на живой записи с двумя повторами подряд — в интеграционных; хранение исходного ASR — запасной ход (+0,5 дня), не делаем без доказанной деградации.
