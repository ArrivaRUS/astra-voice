# Звук для проверки модели

`smoke-ru-6s.wav` нужен для пробного распознавания при установке модели:
после проверки SHA-256 и переноса файлов в каталог ревизии, до выбора модели
текущей. Запись содержит фразу «Проверка связи».

Файл входит в пакет Debian вместе с каталогом `data/smoke/`.
Это точная копия `data/test/test-ru-6s.wav` из репозитория; исходный каталог
`data/test/` при сборке пакета удаляется.

Формат: WAV PCM, 16 000 Гц, моно, 16 бит, 6 секунд. Размер: 192 044 байта.

SHA-256: `0ca1ae8739e1d779dda3a24407ca94628b44faeac55e5aaf52c01a0f9f063ca4`.
