# Звук для проверки модели

`smoke-ru.wav` нужен для пробного распознавания при установке модели:
после проверки SHA-256 и переноса файлов в каталог ревизии, до выбора модели
текущей, а также для самопроверки при загрузке модели (F4.9). Запись содержит
одну фразу «Проверка связи» и небольшой хвост тишины.

Файл входит в пакет Debian вместе с каталогом `data/smoke/`.
Это ровно первые 1,60 секунды (25 600 отсчётов) `data/test/test-ru-6s.wav`
из репозитория, экспортированные стандартным модулем Python `wave`
без изменения формата. Исходный каталог `data/test/` при сборке пакета удаляется.

Формат: WAV PCM, 16 000 Гц, моно, 16 бит, 1,60 секунды. Размер: 51 244 байта.

SHA-256: `25b2afe1fe248a7b6e7238932e10cd7de97d431ee63415de2cbb2031617880bd`.
