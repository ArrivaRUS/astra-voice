## 2. Расхождения и как разрешены

1. **GUI-стек.** Claude #1: top-1 PyQt5 из apt, top-2 Qt6 C++/QML 6.10 (`repository-extended`). Sol #2: top-1 Qt6 C++/QML + sherpa статически («один ELF» под ЗПС), top-2 PyQt5.
   **Разрешение:** заказчик допустил GPLv3 → **PyQt5 из apt — заданное ограничение архитекторам.** Аргумент Sol про «один ELF» для PyQt5-из-apt не работает против нас: системные Python/Qt/numpy уже подписаны Астрой, собственных неподписанных `.so` остаётся 2–5 (onnxruntime + движок) — их подписываем на сборке. Условие отката на Qt6 C++/QML: QML 5.15 не вытягивает макет дизайнера (проверить спайком до G3).
2. **Самоподписанный ключ ЗПС.** #1 (вики): `xattr_keys`/`certs` допускают ключи без подписи изготовителя, регистрация админом. Sol: «самоподписанный доверенным не становится, нужна цепочка партнёра или подпись интегратором заказчика». **Оба верны:** ключ не доверен *автоматически* — его вводит админ по процедуре. Для v1: артефакты «ЗПС-готовые» (все свои ELF/.so подписаны на сборке `bsign-integrator` ключом организации, отсоединённая/xattr подпись) + публичный ключ и инструкция администратору; альтернатива для заказчика — подпись его интегратором.
3. **Полоска качества.** WER гуляет по протоколу (Russian LibriSpeech без постобработки: не-e2e лучше; FLEURS с пунктуацией: e2e лучше). **Разрешение:** одна шкала по одному протоколу (бенчмарк onnx-asr, Russian LibriSpeech) + подсказка «как измерено»; не смешивать источники.
4. **Лицензия Whisper** — MIT в README OpenAI, Apache-2.0 в карточках HF → в NOTICE обе.
5. **Sol сам с собой:** «пресеты sherpa для v3 есть» vs «в каталоге sherpa v3 нет» — репо `csukuangfj` существуют, документации нет → см. §1 «Рантайм».
6. **Tauri-updater и `.deb`** (дока vs changelog) — не важно: Tauri не берём (заказчик уходит от этого стека, худший профиль ЗПС).

## 6. Вход для PRD и архитекторов

- **Каталог v1:** GigaAM v3 e2e_rnnt (дефолт) · e2e_ctc («быстрее») · rnnt («точнее, без пунктуации») ·
  GigaAM Multilingual 220M · T-one · Vosk ru · Vosk small-ru («для слабых машин») · Whisper small int8
  и large-v3-turbo int8 («другие языки; медленно»). Профиль «только отечественные».
- **Манифест каталога:** JSON с repo/commit/файлы/sha256/размер/лицензия/атрибуция/полоски+протокол;
  источник — встроенный, GitHub Releases зеркало, корпоративный URL.
- **Обновлятор:** одна privileged-операция через polkit; проверка подписи манифеста и sha256 до
  установки; детект `DIGSIG_ELF_MODE` → ветка «скачать и передать администратору»; проверка ≤ 1/сутки,
  кеш, backoff; выключатель.
- **Спайки до G3/G4:** (1) PyQt5 + QtQuick 5.15: окно + трей SNI + прозрачная пилюля поверх окон без
  кражи фокуса (главный риск стека, ~1 день); (2) `pkexec apt-get install ./x.deb` из GUI-процесса
  (~0,5 дня); (3) ВМ Astra с включённой ЗПС + наш подписанный `.deb` (~1 день, обязательна — P21½);
  (4) замер трёх вариантов GigaAM через `onnx-asr` (~650 МБ скачивания — нужно «да» заказчика).
