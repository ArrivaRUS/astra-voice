# Тестовые записи

В репозитории лежат `test-ru-6s.wav` и `test-ru-20s.wav` с повторением фразы
«Проверка связи» и паузами: PCM, 16 кГц, моно, 16 бит.

`test-ru-130s.wav` нужен для проверки лимита фразы 120 секунд. В репозиторий
его не кладём: файл занимает около 4 МБ. Он генерируется вместе с короткими
записями командой `scripts/make_test_wav.sh` в каталог вне репозитория
(по умолчанию `$HOME/.cache/astra-voice-spike/wav`):

```sh
scripts/make_test_wav.sh /путь/к/samples/russian.wav /tmp/astra-voice-wav
tools/validate dictation --virtual-mic --wav /tmp/astra-voice-wav/test-ru-130s.wav --limit
```

Путь к сгенерированному файлу передаётся в `tools/validate` через `--wav`.

Длинный файл можно собрать отдельно из лежащего рядом `test-ru-6s.wav`
стандартной библиотекой Python, без sox и исходника transcribe-rs. Из корня репозитория:

```sh
python3 scripts/make_long_wav.py --target <каталог вне репозитория>/test-ru-130s.wav
```

Замените `<каталог вне репозитория>` на нужный путь, например `/tmp/astra-voice-wav`.
По умолчанию длительность — 130 секунд. Каталог создаётся при необходимости;
готовый файл той же длительности не перезаписывается. Результат хранится вне
репозитория и в git не попадает.
