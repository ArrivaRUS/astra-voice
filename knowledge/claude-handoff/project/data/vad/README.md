- Версия: тег `v6.2.1`, коммит `7e30209a3e901f9842f81b225f3e93d8199902b1` (2026-02-24).
- Лицензия: MIT, Copyright (c) 2020-present Silero Team.
- Размер: 2327524 байта.
- sha256: `1a153a22f4509e292a94e67d6f9b85e8deb25b4988682b7e174c65279d8788e3`.
- Контрольная сумма модели лежит рядом в `SHA256SUMS` и проверяется командой `sha256sum -c SHA256SUMS` (её же запускает сборка пакета).
