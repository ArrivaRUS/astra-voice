Заказчик 2026-09-28: «Давай пореже делать проверки ИБ, а то это прямо адски много токенов сжигает».

**Why:** один проход security-analyst (T3 v0.1) — ~400k токенов и ~8 ч с экспериментами; повторные сверки добавляют столько же.
Заказчик уже считает ИБ на бете вторичной ([[feedback-no-security-nagging-beta]]).

**How to apply:** security-analyst звать только на обязательные гейты (T3 перед публичным тегом крупных версий, T2 при реально
новой security-поверхности: ключи, подпись, сеть, права/root) и **одним проходом** — без повторных «сверок закрытия»
(закрытие проверяет code-reviewer или Юрка сам по чеклисту из отчёта). В брифе ограничивать объём: без многочасовых
экспериментов, без второго мнения Astra по умолчанию. Мелкие правки CI/доков/UI — без ИБ. Риски — строкой в decisions/log.md.
