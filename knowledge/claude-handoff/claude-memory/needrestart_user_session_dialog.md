На Astra 1.8 SE заказчика стоит `needrestart`: после каждого `apt install`/`upgrade` он показывает синий
диалог «Демоны, использующие устаревшие библиотеки» с **отмеченным `user@1000z0_0_0x0_0x0.service`** —
это менеджер пользовательского сеанса. Нажатие «Ok» = перезапуск сеанса = зависание и холодный сброс
(заказчик проходил это не раз; 16.09.2026 при установке astra-voice 0.1.0~m5 нажал «Отмена» по моему
предупреждению).

**How to apply:** перед любой командой `sudo apt install …` для заказчика — предупреждать: «если появится
синий диалог, Tab → Отмена». Durable-фикс **применён 16.09.2026** (файл создан, синтаксис проверен):
`/etc/needrestart/conf.d/50-astra-desktop.conf` с `$nrconf{restart} = 'l';` и
`$nrconf{blacklist_rc} = [ qr(^user@) ];`. Не наш пакет и не наша вина; связано с
[[target-environment-astra-1-8]].
