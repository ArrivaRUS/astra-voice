Тексты в интерфейсе утилит (Astra Voice, Astra Cowork) — для обычного пользователя, не для админа.
Заказчик на первом живом показе окна Astra Voice (2026-09-09) попросил убрать: подпись «Создаёт ярлык
~/.config/autostart/…» под тумблером автозапуска и «Sof-hda-dsp · встроенный микрофон» под выбором микрофона.

**Why:** «простому смертному этот комментарий не нужен», «неведомая хрень для пользователя» — технические
детали пугают и не помогают; они уместны в «О программе → Отладка», логах и документации для администратора.

**How to apply:** в макетах, спеке и QML подстроки настроек — только про смысл для пользователя («Удерживайте
и говорите — текст появится там, где курсор»); имена устройств — только `device.description` из PulseAudio,
без ALSA-карт/индексов; пути, юниты systemd, имена файлов — никогда в основных экранах. При ревью макетов
(UX-analyst, DesignReviewer) проверять этот пункт явно. Связано: [[project-astra-voice]].
