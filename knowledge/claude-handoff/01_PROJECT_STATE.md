# Состояние Astra Voice для передачи

Это ориентир по локальным источникам, прочитанным 5 октября 2026 года. GitHub, установленная программа и тесты заново не проверялись. Приоритет имеет самая верхняя запись HEARTBEAT от 2 октября, сохранённая локально без коммита.

## Назначение и устройство

Собственная программа голосового ввода для Astra Linux SE 1.8, KDE и Fly, X11. Python 3.11, PyQt5/QML, отдельный процесс распознавания, GigaAM и дополнительные модели, горячие клавиши, вставка текста и управление моделями. Предыстория — Handy с GigaAM; сведения о ней находятся в памяти и ранних диалогах. [Карточка проекта](project/PROJECT.md), [архитектурный синтез](project/arch/plan-synth.md), [мост интерфейса](project/docs/ui-bridge.md).
